## Qlib 量化研发约定

- 先核对本项目的 Python、pyqlib 版本和数据合同，再选择 API 或示例。
- 共享 Qlib provider 只读；缓存、实验记录、报告和临时文件仅写入项目 `artifacts/`。
- 复权口径、价格/成交量单位、日历和股票池来源必须显式记录；无法验证时标为 `unknown`。
- 特征、标签、切分和成交时点必须给出因果性证据；禁止未来数据和同 bar 不可成交假设。
- 实验必须保存配置、数据 profile、代码版本、Recorder 标识和费用后结果；不得只引用“最新运行”。
- 比较策略时使用相同数据、区间、股票池、费用和账户约束；不满足时明确标记不可比。
- 默认不联网、不安装依赖、不写共享数据、不运行训练/回测、不下单；需要时取得当前任务的明确授权。
- 保留用户已有改动；先展示计划和差异，再执行最小范围修改。
- 用中文报告已验证、未验证、阻塞项和证据路径；初始化成功不代表训练或策略有效。
